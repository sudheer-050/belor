Claude Code and Codex

Play a sound when a run finishes in a Belor tab, and the softer double ping when it asks you a question or needs permission.

Turning one on adds a small entry to Claude Code's settings.json or Codex's config.toml, and saves a backup next to the file. Turning it off removes only that entry. Restart Claude Code or Codex afterwards. Works in PowerShell, Command Prompt and Git Bash tabs, not WSL tabs.

Popup notifications

A desktop popup when the window is minimized or behind other apps. Clicking it brings that tab forward. The taskbar button also flashes.
